# PAIR — Final GeM Bid Compliance UI

This build preserves the existing Next.js/TypeScript API integrations and adds:
- Custom PAIR SVG brand mark
- First-load 2.3s product intro animation (session-scoped)
- Interactive, lightweight AI verification field
- GeM procurement-focused copy and navigation
- Refined enterprise dark visual system
- Custom logo in sidebar, authentication and landing
- Chat PDF attachment and `/api/v1/ai/chat-with-pdf` integration
- Cleaner AI response rendering
- Reduced-motion support

Run:
1. `npm install`
2. Configure `NEXT_PUBLIC_API_BASE_URL` in `.env.local` if needed.
3. `npm run dev`

No frontend AI provider secrets are included.
